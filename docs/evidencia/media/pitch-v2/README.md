# Material visual de arquitectura y plataforma

Estas láminas componen una presentación distinta de la demostración operativa. Se exportan a 1920 × 1080 y
siguen la identidad visual de ArenaPay.

| Lámina | Tema | Tiempo |
|---|---|---:|
| `01-problema.png` | El resultado y el pago dependen del organizador | 00:00–00:18 |
| `02-propuesta.png` | Separar juego, evidencia y liquidación | 00:18–00:38 |
| `03-arquitectura.png` | Flujo técnico completo | 00:38–01:07 |
| `04-motores.png` | `GameEngine`, registro y versiones | 01:07–01:34 |
| `05-evidencia.png` | Testnet, replay, hash y premio | 01:34–01:58 |
| `06-juegos.png` | Juegos reutilizables y límite del póker | 01:58–02:23 |
| `07-roadmap.png` | Evolución posterior al MVP | 02:23–02:42 |
| `08-cierre.png` | Mensaje final y enlaces | 02:42–02:55 |

La miniatura recomendada para YouTube es `arenapay-arquitectura-thumbnail.png`. No contiene etiquetas
internas de producción ni números de versión.

La escena 05 puede combinar esta lámina con un fragmento de 8–12 segundos de
`../arenapay-demo-testnet-es.mp4`. El guion y las instrucciones de montaje están en
[Guion, publicación y metadatos](../../../guias/pitch-v2-arquitectura.md).
