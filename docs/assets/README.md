# Recursos gráficos de ArenaPay

## Logo para galerías y perfiles

- [`arenapay-logo-gallery.png`](arenapay-logo-gallery.png): archivo cuadrado de 1024 × 1024 píxeles
  preparado para subir a Stellar Build, GitHub, redes sociales y directorios.
- [`arenapay-logo-gallery.svg`](arenapay-logo-gallery.svg): fuente vectorial editable del mismo símbolo.

La letra se mantiene dentro de la zona segura central para que no se corte cuando una plataforma
aplique una máscara circular. El fondo azul llega hasta el borde; el amarillo se reserva para el
acento de la marca y la relación visual con el ecosistema Stellar.

El favicon de la aplicación usa la misma geometría con esquinas redondeadas. Para publicaciones no
se debe reutilizar una captura ni recortar el favicon: se utiliza directamente el PNG de esta carpeta.
